# 游戏内连续碰撞检测系统

## 项目描述

游戏内连续碰撞检测系统的bug修复项目。核心模块 `collision/ccd.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 连续碰撞检测完全没做只能做离散碰撞
- 碰撞时间完全没做不能计算碰撞时间
- 扫掠碰撞完全没做不能做扫掠碰撞
- 穿透预防完全没做不能预防快速物体穿透
- CCD性能完全没做不能优化CCD性能

## 运行测试

```bash
python -m pytest tests/test_ccd.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
