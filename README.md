# pairwise-ccd

高速子弹打薄墙直接穿过去：连续碰撞检测只对玩家胶囊做 sweep，子弹还是离散步进；TOI 计算用了上一帧速度，加速度大的抛射物算早/算晚；子步数按固定 4 步，帧率低时步长仍然太大；扫掠球和三角形的接触法线方向反了，反弹穿进墙里；CCD 只检测静态墙，动态门和升降平台被忽略；命中后没有把物体回退到 TOI 时刻，伤害位置偏移。physics/ccd.py 是核心，tests/test_ccd.py 15个红。要修的是：所有快速体做 sweep；TOI 用当前速度+加速度；自适应子步；接触法线朝向；动态体也参与；命中回退到 TOI。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
